# ☕ คู่มือมาตรฐานการตรวจคัดเกรดเมล็ดกาแฟโรบัสตา (Coffee Defect & Ripeness Guide)
**สำหรับพัฒนาโมเดล Computer Vision & Edge AI (TESA Top Gun Rally 2026)**

## 1. การคัดเกรดตามโจทย์ TGR2026

โจทย์กาแฟโรบัสตาชุมพรแบ่งกระบวนการตรวจจับภาพออกเป็น 2 ช่วงสำคัญ:

### ช่วงที่ 1: ตรวจจับระดับความสุกของผลกาแฟสด (Coffee Cherry Ripeness)
ใช้เพื่อแก้ไขปัญหาเกษตรกรเก็บเกี่ยวผลดิบปะปนกับผลสุก
* **Class 0: `unripe` (ผลดิบ):** สีเขียวสดหรือเขียวอมเหลือง
* **Class 1: `ripe` (ผลสุกพอดี):** สีแดงสด (Bright Red) เป็นช่วงที่มีน้ำตาลและความหวานสูงสุด เหมาะแก่การแปรรูป
* **Class 2: `overripe` (ผลสุกงอม/แห้งคารวง):** สีแดงคล้ำ ม่วงเข้ม หรือดำ เริ่มเหี่ยวแห้ง

---

### ช่วงที่ 2: ตรวจจับข้อบกพร่องของเมล็ดกาแฟสาร (Green Bean Physical Defects)
ใช้หลังกระบวนการแปรรูปแบบแห้ง (Dry / Natural Process) โดยอ้างอิงมาตรฐาน SCA และกรมวิชาการเกษตร:

| Class Name | ชื่อไทย | ลักษณะที่สังเกตเห็นได้จากภาพ | ระดับความรุนแรง |
| :--- | :--- | :--- | :--- |
| **`healthy_bean`** | เมล็ดสมบูรณ์ | เมล็ดทรงรี ผิวเรียบ สีเขียวอมฟ้าหรือเขียวมะกอก ไม่มีรอยแตก | เมล็ดดี (เป้าหมาย) |
| **`black_bean`** | เมล็ดดำ | สีดำคล้ำทั้งเมล็ดหรือบางส่วน เกิดจากผลเน่าหรือเชื้อรา | **ตำหนิขั้นรุนแรง (Primary Defect)** |
| **`mold_bean`** | เมล็ดขึ้นรา | มีสปอร์หรือใยราสีขาว เทา เหลือง เสี่ยงสารพิษ **Ochratoxin A** | **ตำหนิขั้นรุนแรง (Primary Defect)** |
| **`sour_bean`** | เมล็ดเปรี้ยว | สีน้ำตาลแดงหรือเหลืองไหม้ เกิดจากการหมักหมมเกินขนาด | ตำหนิปานกลาง (Secondary) |
| **`broken_bean`** | เมล็ดแตกหัก | เมล็ดบิ่น หัก แหว่ง จากเครื่องสีกาแฟ | ตำหนิทางกายภาพ (Secondary) |

## 2. เกณฑ์การตัดสินเกรดกาแฟ (Grading Criteria Logic)

$$\text{Defect Rate (\%)} = \left( \frac{\text{Total Defects Count}}{\text{Total Sample Count}} \right) \times 100$$

* 🏆 **Chumphon Fine Robusta (เกรดพิเศษ):**
  * Defect Rate $\le 3.0\%$
  * **ต้องไม่มีเมล็ดขึ้นรา (`mold_bean == 0`)** และไม่มีเมล็ดดำ (`black_bean == 0`)
  * ความชื้นที่เหมาะสม: 10.5% – 12.0%
* 🥈 **Chumphon Robusta Premium (เกรดพรีเมียม):**
  * Defect Rate $\le 6.0\%$
  * ไม่มีเมล็ดขึ้นรา (`mold_bean == 0`)
* 🥉 **Commercial Grade (เกรดพาณิชย์ทั่วไป):**
  * Defect Rate $6.1\% - 12.0\%$
* ❌ **Reject (ตกเกรด / ต้องคัดใหม่):**
  * Defect Rate $> 12.0\%$ หรือตรวจพบเมล็ดขึ้นราปริมาณมาก
